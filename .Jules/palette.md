
## 2024-05-23 - Accessibility Labels for Abbreviated Badges
**Learning:** VoiceOver reads abbreviated labels like "AD" either as a word (e.g., "add") or spelled out, which can be confusing.
**Action:** Always provide full-word, localized `accessibilityLabel` strings for abbreviated UI elements or badges (e.g., "Advertisement" for "AD") to ensure proper screen reader pronunciation.
