## 2024-03-24 - Accessibility improvements for ad tags
**Learning:** VoiceOver reads the 'AD' badge as individual letters if not properly labeled. In iOS, 'AD' needs a full-word accessibility label ('Advertisement') for screen readers to pronounce it correctly, even if the visual text remains 'AD'.
**Action:** Add accessibility labels to 'AD' tags across NativeAd views.
