## 2024-05-18 - VoiceOver Pronunciation for UI Badges
**Learning:** Abbreviated UI elements or small text badges (like "AD") are often pronounced incorrectly or spelled out by screen readers (e.g., VoiceOver saying A-D instead of "Advertisement"). This creates a confusing and non-inclusive experience.
**Action:** When creating abbreviated UI badges, always provide a full-word `accessibilityLabel` string that conveys the actual meaning to ensure proper screen reader pronunciation.
