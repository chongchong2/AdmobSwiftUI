## 2026-05-05 - VoiceOver Pronunciation of Abbreviated UI Badges\n**Learning:** VoiceOver often spells out or mispronounces short abbreviated badges (like 'AD' for advertisement). For iOS accessibility, these UI elements need explicit, full-word string assignments to `accessibilityLabel` to ensure screen readers speak the intended semantic meaning.\n**Action:** Always provide full-word `accessibilityLabel` strings (e.g., 'Advertisement') for abbreviated UI elements or badges to ensure proper screen reader pronunciation.
