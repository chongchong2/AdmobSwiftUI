## 2024-05-24 - Accessibility Labels for Abbreviated Badges
**Learning:** When using abbreviated badges (like "AD" for Advertisement), VoiceOver screen readers may incorrectly pronounce the abbreviation (e.g., reading "A-D" instead of "Advertisement"). It is necessary to provide full-word `accessibilityLabel` strings to ensure proper screen reader pronunciation. Additionally, even these full-word accessibility labels must be wrapped in `NSLocalizedString` with the correct bundle (e.g., `NSLocalizedString("Advertisement", bundle: .module, comment: "...")`) for proper localization within Swift packages.
**Action:** Always provide full-word accessibility labels for abbreviated badges and ensure they are properly localized using `NSLocalizedString` with the correct bundle context.
