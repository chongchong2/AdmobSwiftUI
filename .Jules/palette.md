
## 2026-07-18 - Full-word Accessibility Labels for Badges
**Learning:** Screen readers like VoiceOver pronounce abbreviated UI elements (e.g., "AD" badges) literally, which can be confusing.
**Action:** Always provide full-word `accessibilityLabel` strings (e.g., "Advertisement") for abbreviated badges or labels to ensure proper screen reader pronunciation. Ensure these strings are localized.
