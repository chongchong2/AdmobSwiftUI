## 2024-05-24 - VoiceOver Pronunciation for Ad Badges\n**Learning:** Screen readers (like VoiceOver) mispronounce abbreviated UI elements (like "AD") if not provided a full-word accessibility label. In localized Swift Packages, `NSLocalizedString` with `bundle: .module` is required even for accessibility labels.\n**Action:** Always map short visual badges ("AD", "PRO") to full-word accessibility labels ("Advertisement", "Professional") to ensure correct pronunciation, and ensure they are localized correctly within the module scope.
